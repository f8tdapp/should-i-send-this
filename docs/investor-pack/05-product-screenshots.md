# BetweenLines AI — Product Screenshot Plan

**Private working document. No actual screenshots are stored here.**

## Capture standards

- Use synthetic messages only; never include real sensitive or third-party information.
- Capture the confirmed release revision and record its SHA/date.
- Hide browser profiles, bookmarks, notifications, developer tools, and environment values.
- Use consistent desktop and mobile dimensions with readable text.
- Prefer PNG, crop deliberately, and keep one clean version without annotations.
- Check spelling, smart quotes, ™ rendering, and focus/loading artifacts before capture.
